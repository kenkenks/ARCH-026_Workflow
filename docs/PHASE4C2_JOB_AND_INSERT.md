# Phase 4C-2 — JOBクラス分離・工程挿入

- `exam.dateAgreement` → `CExamDateAgreementJob`、`exam.resultRegistration` → `CExamResultRegistrationJob` をJOBカタログの実装クラスとして選択可能にした。
- 入力項目は従来の4項目／5項目を維持し、各クラスで定義・検証・一時保持する。
- JOB実行時には、カタログのクラス名とキーワードの組を照合する。その他の一般JOBは従来どおり模擬実行。
- 工程一覧に「＋挿入」「↑」「↓」を追加。挿入は選択工程の**直後**。既存の接続先を新工程へ付け替え、新工程から元の接続先へ接続する。
- 分岐で複数の接続先がある場合、挿入対象の経路を指定する。接続先のない工程とENDの直後には自動挿入しない。
- ↑↓は表示順のみ。工程ID・実行接続は変更しない。
- 既存の実行中チケットへの適用は行わない。定義の保存・バージョン管理は既存の仕様に従う。
- JOBデータは依然としてメモリ上のみ。DB接続は未実装。
