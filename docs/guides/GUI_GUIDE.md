# ARCH-026 ローカルDEV工程モニター

## 起動

```powershell
npm install
npm run gui
```

ブラウザで `http://localhost:3000` を開く。終了はターミナルで Ctrl+C。

- **1工程実行**: 仮ジョブまたはBool判定を1工程だけ実行。
- **最後まで実行**: 最大30工程まで連続実行。
- **リセット**: 完了後に新しい実行IDで初期化。
- Bool判定は `false, false, true` の固定シーケンス。
- localhostのみで待ち受け。外部ネットワーク・Firebase・Cloud Runには接続しない。
- 履歴はメモリのみ。プロセス再起動で消える。
- 既存の `npm run demo` / `npm test` も利用可能。

## 注意

これは独立GUIの検証用であり、道場システムへの統合や運用認証、Firestore永続化は未実装。工程図は固定4工程の表示。実行エンジンは既存の `CWorkflow` を再利用する。

## v0.2 チケット管理

`npm run gui` でローカル画面を起動し、画面上部の「チケット管理」で件名・起案者ID・責任者ID・期限を入力して「下書き発行」。一覧から「提出」し、「実行開始」で既存デモワークフローに関連付ける。工程を最後まで実行するとチケットは完了になる。

現段階のチケット保存はメモリのみ。認証・権限・期限通知・複数ワークフロー同時実行は未対応。既存GUIのリセットは、実行中チケットがある場合は拒否する。
